# 钉钉表达层 V2

## 目标

Jarvis 使用钉钉原生 AI Card，但卡片只是容器。表达层 V2 通过“结论—摘要—行动”
三层结构控制内容密度，使复杂问题第一屏即可读到核心判断，同时保留继续展开的能力。

## 默认卡片结构

1. 核心判断：不超过 120 个汉字；
2. 三至四项速览：每项一个判断；
3. 三项关键行动：不重复前文；
4. 必要时增加一句话汇报结论。

普通回答最多四个区块，每个区块最多三个要点。详细报告、正式公文和用户指定格式
不受默认长度限制，但仍应先给结论。

## 模板视觉建议

在钉钉卡片模板编辑器中保留现有 `content` Markdown 变量，并在变量上方增加一个
静态标题区：

- 标题：`JARVIS · 智能分析`
- 背景：浅橙色 `#FFF3E8`；
- 主文字：深灰色；
- 强调色：平安橙 `#F05A23`；
- 正文：白底，不增加外层边框和重复标题；
- 页脚：可选用浅灰小字 `重要决策请结合业务实际复核`。

静态标题由模板负责，模型正文不再重复“Jarvis 分析”“Codex 回复”或任务编号。

## 部署

代码更新后执行：

```bash
chmod +x scripts/*.sh
./scripts/upgrade-presentation-v2.sh
```

脚本会先备份，再安装新版 Skill、安全策略并重启，最后验证
`presentation_version=2`、Codex final-only、AI Card 配置和容器健康状态。

## 人工验收问题

```text
分析一下平安开展线上经营的优势、劣势、机会和风险，并给出推进建议。
```

通过标准：第一屏出现核心判断；正文不使用英文栏目名；默认不把 SWOT 四部分全部
展开成长文；建议不超过三项；不展示 Thinking、工具调用或知识库路径。
